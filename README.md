# Sony WF-C710N · Perfil de Easy Effects

Perfil personal de salida para los audífonos Sony WF-C710N.

## Cómo usarlo

1. Descarga [Audifonos.json](./Audifonos.json). Si GitHub muestra el contenido del archivo, usa el botón de descarga del archivo original.
2. Abre Easy Effects y selecciona **Salida → Perfiles → Local**.
3. Usa la opción de importar un perfil, elige el JSON y carga **Audifonos**.
4. Selecciona los Sony WF-C710N como salida de audio del sistema.

El perfil combina ecualizador, potenciador de graves, excitador, herramientas estéreo y limitador. El convolucionador está desactivado. Si decides activarlo con el ajuste guardado, tendrás que importar por separado la respuesta al impulso `dolby-music.irs`.
